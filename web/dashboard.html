按你要做的事查阅

怎么组合筛选条件？

常用条件直接显示。机构类型、等级等次、科室来源、协作网络和距离条件在“更多条件”中。多个条件需要同时满足，添加条件后结果通常会减少。

例如查找海淀区三级机构：选择“行政区 → 海淀区”和“医院等级 → 三级”。如果需要三甲，再在“更多条件”中选择“等级等次 → 甲等”。

已选条件会显示在筛选区下方，点击条件旁的 × 可单独取消；“清空条件”恢复默认查询。

怎么阅读医疗资源分析图表？

先选择区域集中度、基层服务结构、科室证据覆盖或协作网络覆盖。条长表示收录的机构数量，悬停可查看数值，“查看分析数据表”可读具体明细。

展开“详细图表分析”，再切换机构结构、科室与专科、区域对比、网络与数据。区域排名可选择比较指标；区域或科室图表支持进入对应机构列表，机构排名可打开详情。

分析使用当前查询条件。比较全市前请先清空筛选；机构数量和挂牌专科数量不代表服务质量。机构总数、参评等级机构数、有来源记录的机构数是不同口径。

智能问答可以问什么？

描述区域、机构类型、等级、科室或统计维度即可。系统先展示真实查询结果，再补充智能说明；模型繁忙时，仍可点击“查看完整结果”继续筛选。

示例只填入输入框，由你确认发送。本系统用于机构资源查询，不提供疾病诊断和用药建议。

怎么收藏、对比和导出？

点击机构行右侧星标可收藏，再点一次取消。选择左侧的对比按钮，选满 2–3 家后点击底部“开始对比”；表中展示的是公开数据收录值。

在“更多操作”中可保存当前筛选方案、复制条件或导出结果 CSV。导出包含全部匹配机构，而不只是当前页。专题分析还有单独的导出按钮。

收藏和筛选方案只保存在当前浏览器，清除浏览器数据后可能丢失，也不会自动同步到其他设备。

怎么按距离查找机构？

在“更多条件”中输入地址并点击“设置参考点”，或使用“我的位置”。默认参考点是天安门；定位需要浏览器授权和可用的定位服务。

直线半径支持大于 0、且不超过 200 千米，只统计高精度坐标机构。粗略坐标会显示“约”，不参与半径筛选。直线距离不是驾车距离或出行时间，实际路线请使用地图导航。

怎么找医生并预约？

左侧“找医生”可按姓名、医院、科室及行政区筛选；医院详情的“医生”标签可以直接查看该院已收录资料。智能问答支持“北京协和医院有哪些心内科医生”。核对官网资料后，复制预约信息并前往北京114，搜索医院、科室、医生。当前为首批部分资料；没有收录不代表该院没有医生。

遇到问题时

没有结果，应该怎么办？

先看“筛选依据”，其中“取消后命中”表示去掉这项条件、保留其余条件时的数量。优先取消能恢复结果的条件，或减少关键词、放宽等级和区域。

为什么有的科室、电话或地址显示未收录？

公开来源覆盖范围不同，未收录不代表机构没有该项服务。“有来源记录”与“名称或规则推断”会分开说明；确认当前联系方式和科室服务时，请以机构官方信息为准。

为什么问答显示本地查询结果？

智能说明依赖模型服务，可能因网络、配置或限流暂时不可用。本地结果仍由机构快照真实筛选得到，可以继续打开完整列表、查看详情和导出。

有哪些键盘操作？

/ 或 Ctrl / ⌘ + K 进入机构搜索；问答中 Enter 发送，Shift + Enter 换行；Esc 关闭弹窗或退出问答。图表分类可用左右方向键切换。

想了解资料是否齐全？

页面顶部的“?”和左侧“帮助与数据说明”可随时回到这里。使用上方栏目查看数据来源、质量与系统范围。

数据规模 DATA SCALE
