系统定位与两种用法 FILTER vs LOOKUP

本系统是北京市医疗机构数据智能分析与筛选平台，回答的是"北京有哪些医疗机构、资源怎么分布、按条件怎么筛出来"。
① 智能筛选（主入口）：用自然语言描述条件（行政区 / 机构等级 / 机构类型 / 所有制 / 数据来源 / 排序），或直接组合条件 → 系统解析成结构化筛选条件 → 查询真实机构数据 → 统计概览 + 地理分布 + 机构列表 + 横向对比。
② 数据查阅：数据总览 / 医疗资源分析 / 机构查询 / 数据整合 / 数据质量，把整合后的数据摊开供查阅。
需要明确的边界：系统只处理机构资源数据，不提供疾病诊断、用药建议、挂号推荐，也不做医学知识问答——数据集里没有患者诊疗数据。自然语言模块的职责仅是把中文翻译成筛选条件；所有机构名称与统计数字都来自数据库的真实查询结果，不生成、不编造。

数据规模 DATA SCALE

与官方公布的 11,994 家差额 2,203 家，主要是基层医疗机构口径缺口（朝阳 / 海淀 / 通州等区的村卫生室与社区卫生服务站）， 官方完整数据集需注册登录后下载，公开渠道无法匿名批量获取。
