# 医疗资源分析、问答与导航更新

系统题目保持与 docs/毕业论文.md 一致。本轮沿用简洁查询布局，新增四个专题，默认一次只看一个专题，原有详细图表可展开查看，展开后再初始化以避免隐藏容器零尺寸。

| 分析方向 | 新增指标 | 解读边界 |
| --- | --- | --- |
| 区域集中度 | 各区机构数及占比、三级医院数、三级机构占比、前三个区域占比 | 没有人口与面积分母，不解释为人均供给或资源密度 |
| 基层服务结构 | 社区机构、村卫生室、诊所与门诊部、医院数量及社区占比 | 统计机构类型，不推断服务量或医疗能力 |
| 科室证据覆盖 | 科室映射机构数、有来源记录机构数及覆盖率 | 没有来源记录不等于没有科室 |
| 协作网络覆盖 | 各区去重成员、儿科医联体、卒中中心、市级新生儿与孕产妇救治机构 | 同一机构可属于多个网络，分项不可直接求和 |

四个专题共用当前筛选结果，支持区域下钻、键盘切换专题和导出本专题。导出包含快照日期、筛选条件与统计口径，比例列以浅色长度辅助比较。数据仍为 2026-10-18 快照。

智能问答改为独立页面，取消遮挡分析图的浮动大窗；保留返回上一页、清空对话、示例提问与真实结果进入查询的能力。欢迎说明合并为一句引导，边界说明改为底部短提示，保留在线与本地模板状态。没有改变问答引擎或模型事实约束。

导航分为“查询与筛选”“资源分析”“智能助手”“数据治理”，系统说明置于独立辅助区。问答页仅突出智能问答，并在返回时恢复之前页面与导航状态。

验证覆盖：四个专题聚合、网络去重、来源口径、真实快照与筛选结果总量、零结果、问答返回导航、明细图表懒初始化及原有交互回归。HTML 检查验证唯一 ID 和 aria-controls / aria-labelledby。没有进行真实浏览器视觉验收、MySQL 联调或模型调用测试。
