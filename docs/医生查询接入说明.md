用户已选择“没有授权名录或接口，继续按医院官网逐院补录”。预约统一保持北京114：https://www.114yygh.com/ 。

## 当前真实覆盖

目标是当前机构快照中的全部三级医院类/妇幼保健记录，包含三甲。三级不等于三甲，可勾选“仅看三甲医院”。目标168条机构记录，其中99条标为三甲；含院区、旧称和需复核的历史记录，不能当作168家独立在营医院。

目前收录12个医院ID的108条医生资料：协和4、北医三院7、中日友好1、北大第一1、北大六院56、天坛1、安贞2、清华长庚1、朝阳1、回龙观11、怀柔11、垂杨柳12。另有协和东/西院区明确关联医院级资料，所以目标记录中有14条能查到部分医生，154条尚待补录。没有医院被标为全院全科室完整名录。

医生资料来源是医院官网个人介绍、医生团队或科室名单。11条回龙观资料和北大六院钱英的专业方向没有收录，明确标记未收录；不能将科室整体专长自动赋给个人。北大六院官网采用“门诊医生”栏目分类，页面如实标出该栏目，不推断具体亚专科。陆林官网标注“教授”，展示此原始口径。

核验日期2026-10-19表示本次查阅公开资料的日期，独立于机构快照2026-10-18，不是医院资料发布日期或实时在岗确认。所有出诊院区、时间、费用和号源以医院及114最新信息为准。

## 使用

左侧找医生支持姓名、行政区、三级医院、科室及三甲条件组合，刷新保留条件，结果按姓名分页。医院详情“医生”标签可进入该院列表。智能问答通过真实本地目录查找，不让模型生成医生：如“北京协和医院有哪些心内科医生”“北京怀柔医院有哪些心内科医生”。

查到后查看官网来源，复制医院/科室/医生，再到114首页自行搜索。未构造医生预约深链，未接入实时号源或挂号订单。

## 数据与批量维护

- `web/doctors_data.json`：已发布真源，按机构ID关联；`source_hosts` 按医院限制可用官网域名。
- `etl/scrape_pkuh6_doctors.py`：低频获取公开官网字段，支持已有结果续采；输出 pending_review，不直接发布，遇验证或拦截停止。
- `etl/import_doctor_records.py`：JSONL批次预检，逐条核实后 reviewed=true；--apply 校验后原子写入并保存旧版。拒绝无效医院、未知域名、重复、未来日期、未核实批次。不会擅自覆盖同院同科同名记录。
- `etl/report_doctor_coverage.py`：生成全部168条目标的逐院覆盖CSV/JSON，保留部分/缺失状态，目录链接不计为医生覆盖。

```sh
python etl/import_doctor_records.py reviewed_batch.jsonl
python etl/import_doctor_records.py reviewed_batch.jsonl --apply
python etl/report_doctor_coverage.py
bash web/build_spa.sh --no-db
```

后端 `/api/doctors` 支持 name/hospital/department/district/grade/page/page_size，grade=三甲。`/api/inst/<id>/doctors` 返回医院级资料；院区不会自动继承无证据的关联。API按记录ID稳定排序，前端按中文姓名排序。

本轮有公开页面返回403/418或访问验证，未绕过验证，也未导入验证页内容。其他尚未核实的医院仍保留为待补录。本功能仍未达到全市三级医院医生全覆盖。
