## 可重复执行

在本材料目录打开终端，PROJECT设置为实际毕设目录；需要Python3.13、Docker及已有mysql:8.0镜像、可读取的源数据库。新机器应先按项目原有部署说明恢复数据服务。本脚本验证数据服务副本到应用启动的恢复链路。

```sh
python3.13 -m venv .venv-verify
.venv-verify/bin/python -m pip install -r requirements-verified.txt
.venv-verify/bin/python scripts/build_analysis.py --project "$PROJECT" --out results/recheck
read -s SOURCE_DB_PASSWORD
export SOURCE_DB_PASSWORD
.venv-verify/bin/python scripts/verify_isolated_deployment.py --project "$PROJECT" --out results/recheck
unset SOURCE_DB_PASSWORD
```

密码通过环境变量传入，不写入结果文件。源数据库容器默认hospital-mysql，可用--source-container更改。该验证通过Docker管理的独立卷运行，宿主端口仅监听127.0.0.1。requirements锁定当前实测版本；其他Python/平台需再验兼容性。
