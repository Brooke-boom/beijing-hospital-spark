## 结果

1. 区域主图支持全部类型/三级，以及数量、占当前范围同类记录比例、三级占本区全部机构记录比例。比例分母明确展示，悬停显示原始数量及分母。降序排序、摘要、复制与专题CSV随指标更新。三级条形图下钻带上三级条件。全量三级180，朝阳/海淀/西城各28，占当前三级15.56%；按本区全部机构记录计算时，石景山6/111=5.41%。这不是三级占医院的比例，也不是人均供给。
2. 科室页先展示三个互斥类别：有公开来源772、仅名称或规则映射5973、未映射2933；百分比四舍五入可能合计100.01%。主图使用各区来源覆盖率，悬停显示分子分母。昌平489/1309=37.36%，占全市有来源记录489/772=63.34%，说明来源采集集中，不能据此排名实际科室能力。科室矩阵移入补充详情，保留当前范围TOP10（手机TOP6）及来源机构下钻；无来源子集显示明确空状态。
3. 网络页用四条横向条形图比较44/67/7/18，主结论突出四网络去重92。儿科与卒中共同成员22、合并去重89、占比24.72%。完整交集矩阵保留在补充详情，网络图不再被误解释为行政区下钻。成员次数不能直接相加为机构数，更不代表服务或转诊能力。
4. 数据治理保留字段覆盖横条；坐标精度改为百分比堆叠条。独立披露历史治理审计：9789→9678，合并删除112、拆分新增1、净减少111，来源为治理规则及备份差集重建报告；另一报告记录剔除2条汇总行。不同阶段不重复相加，不把13803→9678的全部净减少当去重。
5. 每专题默认呈现主问题、主图、发现与限制，方法和技术记录折叠，补充图不占默认页面。科室挂牌图仍在详细分析。专科TOP切换移入相关详情；复制改为当前专题摘要，全量导出明确标为全部分析数据。本专题CSV含当前主图指标、分母、发现、限制和补充矩阵，避免混淆。
