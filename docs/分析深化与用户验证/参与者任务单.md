# 毕业设计系统试用任务单

感谢参与。本次评估的是系统，不是你的能力。请按自己的理解操作，找不到或看不懂也请直接说。无需提供个人信息、注册账号或实际预约，随时可以停止。预计15—20分钟。

系统地址：使用开发者电脑时打开 http://127.0.0.1:5001/ 。这是本机地址，其他电脑不能直接访问；建议在同一台电脑上依次试用。

1. 查出北京市全部三级医院记录，再筛选海淀区，说明两次的数量。
2. 找到“医疗资源分析”，指出三级记录最多的区域，并解释该图能否证明哪个区医疗不足。
3. 查看科室来源分析，说明“有科室映射”和“有来源记录”的区别。
4. 找到一家有资料的三级医院医生，查看科室和信息来源，再打开114预约入口。不必登录或完成预约。
5. 查看协作网络，判断儿科44与卒中67能否直接相加得到独立机构数。

每项结束后请告诉主持人：哪里最难找？哪里让你不确定？最后请评价整体操作容易程度1—5分（1很困难、5很容易），以及最希望改进的一处。
