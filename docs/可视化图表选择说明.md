# 可视化图表选择说明

更新：2026-10-22。图表随当前机构筛选范围计算；保留原始快照与指标定义。

| 问题 | 图表 | 理由 |
| --- | --- | --- |
| 行政区空间分布 | 分区设色地图 | 位置与空间格局；散点按需启用 |
| 区域数量排名、机构TOP | 横向条形图 | 统一零基线比较数量，长名称易读 |
| 办别、坐标精度构成 | 环形图 | 少量互斥类别占总体的比例，保留小比例精确读数 |
| 类型与办别、基层结构 | 堆叠条形图 | 同时比较总量与类别组成；百分比图注明分母 |
| 科室×区域、区域×等级 | 热力矩阵 | 两个离散维度的交叉分布，可点击下钻 |
| 专科数量是否集中 | 经验累计分布阶梯曲线 | 横轴专科名称数，纵轴不超过该数的累计机构占比，只统计有名称的90条记录 |
| 国家级与市级专科比较 | 成对点图 | 同一数量轴比较两类条目；原始数量可见，零值不省略 |

累计分布是截面分布，不是时间变化；不能用曲线斜率解释增长趋势。成对点图不将两层级相加为跨层级去重数。图表种类服务于分析问题，不使用医疗实力雷达、没有真实时间序列的趋势线或暗示真实流转的桑基图。
