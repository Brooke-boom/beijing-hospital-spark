## 复现步骤

1. 将web/snapshot_data.json的institutions输出JSONL，同时保存snapshot_time、project_metrics.fingerprint和文件SHA256元数据。
2. 使用spark/jobs/dim_research_topics.py，传入JSONL URI、元数据JSON、输出JSON路径；PYTHONPATH包含spark/jobs，JDBC包为com.mysql:mysql-connector-j:8.4.0。
3. 将结果保存web/analysis_batch.json，运行etl/verify_research_batch.py。
4. 使用research_cluster_experiment.py对同一JSONL执行聚类，保存特征、随机种子及结果。
5. node etl/benchmark_offline.js；bash web/build_spa.sh --no-db。

冻结输入元数据另存data/processed/research_analysis/input_meta.json。

一键复现入口：`bash spark/run_research.sh`。需已启动Spark/HDFS/MySQL容器，解释器包含PyMySQL。该命令重算独立研究结果表，不执行上游清洗。
