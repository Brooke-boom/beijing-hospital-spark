# 项目说明书

当前实现、运行方式与边界统一见[README](../README.md)、[当前指标](当前项目指标.md)、[验证报告](发布验证/current/验证报告.md)和[收尾同步说明](收尾同步说明-20261021.md)。

主要页面为机构查询、找医生、数据总览、医疗资源分析、智能问答及帮助与数据说明。前端使用原生JavaScript与ECharts，Vue为历史实现。专题和相关详细图表统一展示，使用地图、条形、环形、堆叠、柱状及热力矩阵。来源缺失与推断分开记录。

机构9,678条、医院类型681条、社区类别1,455条、三级180条。医生20条目标部分覆盖、160条待补录。当前回归20项执行入口通过，真实用户试用及最终全链路、生产并发仍待验证。
