# 前端简化说明

系统顶部及浏览器标题统一为《基于Spark的北京市医疗机构资源整合与多维筛选可视化系统》，与 docs/毕业论文.md 的题目一致。

查询页默认保留关键词、行政区、医院等级、科室四项；机构类型、距离、等级等次、科室来源及协作网络统一放入“更多条件”。保存方案、复制条件、导出、快捷筛选及结果统计放入“更多操作”。默认隐藏重复的面包屑、查询说明、快照提示、统计卡和重复数量，结果列表提前展示。清空条件保持直接可见。

去掉查询外层大卡片及每条结果的独立框线，采用留白和行分隔；侧栏保留分组名称，去除分组横线和重复说明。完整标题在窄屏换行显示。

验证：Python、筛选解释、页面脚本、20 项交互工作流、产物一致性、413 项离线双引擎断言及离线性能检查通过。额外检查完整题目、常用字段、默认折叠、唯一 ID 和 aria-controls 关联。尚未完成真实浏览器视觉验收。

数据仍为 2026-10-18 快照，本次没有刷新机构数据。
