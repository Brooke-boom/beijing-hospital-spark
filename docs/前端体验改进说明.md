# 前端体验改进说明

本次版本在既有离线单文件系统上完善用户流程，没有引入账号、付费服务或新的部署依赖。数据快照仍为原批次，界面更新不代表数据更新。

## 主要变化

- 默认进入机构查询。页头显示当前位置、当前数据范围与快照状态；数据总览另设开始查询入口。
- 左侧按任务分组，移动端提供底部常用导航和可展开完整菜单。菜单和弹窗支持 Escape、焦点隔离与关闭后焦点返回。
- 输入采用短防抖并兼容中文输入法；关键词联想具有组合框状态。无效半径与有效的零结果分别展示。
- 机构名称、收藏、对比和条件移除均为可用键盘操作的按钮。详情标签支持方向键、Home 和 End。
- 智能问答结果可一键转入完整机构列表，保留多行政区、证据和半径条件；用户可在该范围内继续筛选。保存带半径的范围时会保留原查询参考点。
- 常用条件可命名保存，最多 8 个，仅保存在当前浏览器；方案删除和收藏清空提供短时撤销。
- 可复制筛选条件、导出全部当前结果 CSV。自动复制不可用时提供手动复制弹窗。CSV 标注日期和证据口径，并防止文本被表格软件作为公式执行。
- 对比页在联网和离线两种路径中均按当前参考点计算距离，粗精度值标注“约”，旧请求不会覆盖已关闭或换过机构的对比。
- 联系方式先用已有快照呈现；接口失败时不会留下永久加载态。请求设有超时，本地查询与模板可继续使用。进入页面不再主动请求定位。
- 图表按页面懒初始化，筛选时只更新当前可见分析页。修正零结果地图回退全量、分析汇总出现 1 家，以及部分分析图忽略科室证据与半径的问题。
- 在保留来源与技术说明的同时，将主操作区中的实现术语换成面向用户的说明。系统说明页新增简短使用指南。

## 验证与使用

双击 `web/dashboard_offline.html` 可使用整合后的离线版。修改后通过 `PYTHON_BIN=python3 bash web/build_spa.sh --no-db` 重建；数据更新时必须带库构建。

运行 `python3 etl/validate_release.py` 可生成同批次验证归档，其中包含新增前端流程测试。具体结果见 `docs/当前版本验证结果.md`。

本次的前端流程检查使用 DOM 模型，覆盖初始化、方案恢复、智能结果范围、半径基准、分析口径、导航与历史恢复、焦点管理、剪贴板降级和 CSV 导出。它不能替代真实浏览器、移动设备、辅助技术及线上服务验收。

浏览器预览受当前工具环境及本地文件访问策略限制，未完成实际视觉验收；HTTP 服务性能仍未测量。正式对外使用前，应在目标浏览器检查 375/768/1440 像素宽度、明暗主题、触摸键盘与下载行为，并在最终服务环境完成真实接口测试。
