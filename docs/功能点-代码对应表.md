### 3.3 运行模式（复盘标准④：Maven 单机模式）

```bash
# 默认：单机模式（Driver 在本容器内多线程并行）
bash spark/run_all.sh

# 可选：Standalone 集群模式（同一份代码、同一份 Maven 坐标，只换 --master）
SPARK_MASTER=spark://spark-master:7077 bash spark/run_all.sh
```

| 要素 | 落地位置 | 说明 |
|---|---|---|
| master 切换 | `spark/run_all.sh` `SPARK_MASTER="${SPARK_MASTER:-local[*]}"` | 默认单机；集群模式需 `spark-worker` 在跑（脚本内已做前置校验） |
| **Maven 依赖声明** | `spark/pom.xml` + run_all.sh `PACKAGES="com.mysql:mysql-connector-j:8.4.0"` | 依赖用 Maven 坐标声明，由 `spark-submit --packages` 交给 Ivy 解析，**不再手工 `--jars` 挂 jar** |
| 依赖缓存 | `spark/.ivy2`（挂载到容器 `/opt/workspace/jobs/.ivy2`） | 首次联网解析后本地留存，**答辩现场无网也能复用** |
| 依赖矩阵导出 | `mvn -f spark/pom.xml dependency:tree` | 附录列完整依赖矩阵用 |

**排错要点**：

1. `formatter` 传函数时 ECharts **不做** `{b}/{c}` 模板替换，必须返回拼好的字符串
   （`p.name + '\n' + p.value`），否则图上会直接印出 `{b}`。
2. 饼图分片过小时标签会重叠，用 `formatter: (p) => p.percent >= 5 ? ... : ''` 抑制，
   数值改由图例 `legend.formatter` 给出。
3. `.chartbox` 必须给显式高度（`styles.css` 里统一 292px / `.tall` 380px），
   否则 ECharts 容器高度为 0，图白屏。
