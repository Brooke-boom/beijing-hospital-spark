### 2.4 机构更名同步（2026-09-10）

在 A 类全量比对中，有 3 个关键词在系统内检索不到，一度被判定为"数据缺失"。逐条核实后确认：**并非缺失，而是主表沿用旧名/简称**，与 A 类名单（用现名）用词不一致导致关键词匹配失败。三家机构的**等级原本就正确（均为三级）**。

| A 类名单用词 | 系统原名称 | 系统 id | 更名事实 | 等级 |
|---|---|---|---|---|
| 空军特色医学中心 | 空军总医院 | 1522 | 2018-11 由空军总医院更名 | 三级 ✓ |
| 空军特色医学中心 | 中国人民解放军空军总医院 | 1481 | 同上（医保名单全称） | 三级 ✓ |
| 通用航天医院 | 中国航天科工集团七三一医院 | 1185 | 2026-02 挂牌更名为北京通用航天医院 | 三级 ✓ |
| 通用航天医院 | 中国航天科工集团七三一医院 北京航天医院 | 1186 | 同上 | 三级 ✓ |
| 北大国际医院 | 北京大学国际医院 | 1354 | 全称/简称差异（非更名） | 三级 ✓ |

**处理方式**：采用「现用名（原旧名）」格式更新 `name` 字段，**不新增记录**（避免产生重复机构），使新旧叫法在前端关键词检索中均可命中：
- `空军特色医学中心（原空军总医院）`
- `中国人民解放军空军特色医学中心（原空军总医院）`
- `北京通用航天医院（原中国航天科工集团七三一医院）`
- `北京通用航天医院（原北京航天医院）`
- `北京大学国际医院（北大国际医院）`

**结论修正**：此前"缺失两家 A 类三级机构（军队/央企系统医院录入缺漏）"的判断**不成立**，予以撤销。系统在 A 类名单上的收录完整度为 100%。

## 三、重点专科数据核实

- 系统含 `national_specialty`（国家级临床重点专科）42 家、`municipal_specialty`（市级重点专科）77 家、`feature`（L1/L2/L3 分级擅长科室）2,354 家。
- 抽样核对（协和、阜外、肿瘤、北大医院、人民医院）科室命名规范、与官方重点专科方向一致，**未发现明显错标**。
- **已知缺口**：阜外心血管病医院作为国家心血管病中心，`national_specialty` 字段为空（源数据未录入），属数据完整性问题，建议在论文中说明专科字段覆盖率（42/9,789 ≈ 0.4% 的重点专科标注集中在头部医院，符合"重点专科集中于三甲"的现实分布）。

**口径差异说明（论文须注明）**：
- 系统 9,789 家 vs 官方 2023 年公报医疗机构 12,298 家，差 **2,509 家**。
- 差额主要来自**基层机构口径缺口**：官方含村卫生室 2,891 家、社区卫生服务中心(站) 2,143 家等，源数据集未全量覆盖。
- 医院类 732 家 vs 官方医院总数 765 家，差 33 家（多为民营/专科未全量录入），吻合度 95.7%。
- 通州（181）、门头沟（50）等区数量偏低，反映源数据各区完整度不均，属数据采集覆盖问题，非错标。

## 五、已知数据缺口（非错误，建议论文说明或后续补充）

1. ~~**缺失两家 A 类三级机构**~~ —— **已于 2026-09-10 撤销**。经核实两家（空军特色医学中心、北京通用航天医院）**均已在系统中**且等级正确，此前系旧名导致检索不到；现名已同步，A 类名单覆盖率 100%（详见 2.4 节）。
2. **机构名称时效性**：主表部分记录沿用旧院名（尤其 2018 年后更名的军队医院、2026 年更名的央企医院），已针对 A 类名单覆盖到的 5 条做同步；其余未覆盖机构仍可能存在旧名，属源数据时点差异，建议论文中说明"机构名称以源数据集采集时点为准"。
3. **七三一医院重复记录**：1185 / 1186 为同一机构两条记录，已统一为三级（本次一并更新为现用名）。
4. **专科字段覆盖有限**：重点专科仅头部医院有标注。
5. **基层机构缺口**：如前所述，与官方总量差 2,509 家。

## 六、修正链路与可复现性

所有修正均通过 `etl/fix_levels_batch1~3.py` + `etl/verify_levels_batch2~3.py` + `etl/fix_renamed_institutions.py` 回溯执行，同步更新主表 → wide 表 → MySQL(`ads_inst_search.level_norm`) → 快照(`web/snapshot_data.json`) → 离线大屏(`web/dashboard_offline.html`) 四层，并由 `bash web/build_spa.sh` 重新生成。

| 脚本 | 用途 |
|---|---|
| `etl/fix_levels_batch1~3.py` | 三批等级修正（升/降级） |
| `etl/verify_levels_batch2~3.py` | 以 A 类名单为基准的交叉核验与冲突检出 |
| `etl/fix_renamed_institutions.py` | 机构更名同步（2026-09-10），主表/wide/MySQL 三层一致更新 |
| `etl/integrate_networks.py` | 医疗协作网络字段（`net_*`）整合 |

每次数据修正前均在 `data/processed/backup/` 生成时间戳备份（如 `master_before_rename_20260910_142638.csv`），可随时回滚。
