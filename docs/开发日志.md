### 关键决策记录
| 决策点 | 结论 | 理由 |
|---|---|---|
| 计算引擎 | Spark 3.5.3（PySpark） | 满足毕设"大数据"定位；官方镜像原生支持 arm64 |

- **去重合并**：规范化机构名（去空格/统一括号/去"北京市"前缀）作为归并键；按字段丰富度择优合并；`src_count` 记录多源交叉验证次数。原始 13,803 条 → 9,791 家。

- **区名清洗**："北京昌平区"等脏值 → 标准区名，仅 42 家（0.4%）无法识别区。

## 2026-09-11（收尾）：仓库同步校验工具 + 补齐遗漏提交

### 问题
本项目用 GitHub Git Data API 提交（沙盒内 `git push` 不可用），commit/tree/blob 对象只存在远端，本地 `.git/objects` 缺这些对象，导致 **`git status` / `git diff` 直接报 `fatal: bad object HEAD`**，无法判断"有没有改动没推上去"。此前几轮改动因此存在**静默漏推**：`docs/开发日志.md`、`docs/数据联网核实报告.md` 的本地更新一直没进远端。

### 方案
新增 `etl/api_verify_sync.py`：绕开本地对象库，直接拉远端 tree，把每个 blob 的 SHA 与本地文件重算的 git blob SHA 逐字节比对。依赖两个仍可用的本地 git 能力：`git ls-files -z`（跟踪清单）与 `git ls-files -o --exclude-standard -z`（未跟踪且未被忽略的新文件）。

**关键设计**：本地索引在 API 提交后**不会更新**，所以"未跟踪"清单里会混入大量其实早在远端的文件。因此必须以**远端 tree 作为权威清单**做二次过滤，否则误报一片（首版就误报了 17 个）。

### 首次运行发现的问题
- `docs/开发日志.md`、`docs/数据联网核实报告.md` 本地有未推送改动（对照远端 diff 确认为正常演进，非误改）。
- `docs/答辩与简历讲解手册.md` 属"防抄袭不入库"材料，但**没在 `.gitignore` 里**，存在被误提交的风险 → 已补规则。
- 4 个一次性提交脚本 `etl/api_commit_*.py` 属临时脚手架，已加 `.gitignore` 规则（通用工具保留为 `etl/api_verify_sync.py`）。
- 密钥扫描：全仓正则扫 `sk-*` / `ghp_*` / `github_pat_*`，无命中。

### 经验
**"推送成功"不能靠 `git push` 的输出判断。** 本环境里 `Everything up-to-date`、fatal 报错、后台任务 failed 都不可信。唯一可靠判据是**把远端内容和本地内容逐字节比一次**——这也是这个校验脚本存在的意义。日常收尾固定跑一遍 `python3 etl/api_verify_sync.py`。

### 【重要修正】图标"看不见"的真正根因：SVG 缺 `<path>` 包裹（commit `7b0e600`）
**现象**：用户两次反馈图标不显示。第一次误判为"对比度太低"（只调亮了导航非激活态 `currentColor`），问题依旧。
**根因**：生成的内联 SVG 把 path 数据写成了 `<svg>` 的**裸文本内容**（`<svg …>M4 4h7v7H4z…</svg>`）。而 SVG 几何必须写成子元素 `<path d="M4 4h7v7H4z…"/>`，**裸文本不是图形 → 一个像素都不画**。当时 favicon 恰好写了 `<path>`，所以唯独它正常；其余 10 处静态 + `svgIcon()` 动态共 57 处全废。DOM 里 `svg.ic` 数量正常（38 个），因此**"DOM 里有 svg" ≠ "能画出来"**。
**定位方法**：① 用 PIL 裁切用户截图放大目视（注意生产文件里内联脚本字符串含伪 `<body>`，抽取静态骨架须取主 `</style>` 之后的那个 body）；② 造最小 HTML 逐变体对比，确认 `stroke` + `<path>` 能画、纯文本内容不画、`fill` 填充线段路径也不画。
**修复**：`svgIcon()` 返回值 `+ p +` → `+ '<path d="' + p + '"/>' +`；`dashboard.html` 10 处静态 SVG 用正则 `<svg class="ic"([^>]*)>([^<]+)</svg>` → `<svg class="ic"\1><path d="\2"/></svg>` 统一包裹。
**顺带修掉两处**：① logo `fill="currentColor" stroke="none" style="color:var(--acc)"` = 蓝底画蓝图标（自隐），改为 `fill="none" stroke="currentColor"`，用 `.mark` 的深色 `#0a0b0d`；② 遗留的 `.ic{width:14px;height:14px;…}` 与新版 `.ic{width:16px;…}` 冲突（后者在前会输），删掉遗留规则。
**验证（这次做了目视）**：把离线包 CSS + 静态骨架抽离单独渲染截图，肉眼确认 logo + 五个导航图标全部显示；生产文件 `<svg class="ic">` 含 `<path>` = 11、裸文本 = 0；Flask 重启后 served 同样 0/11。

### 经验
**内联 SVG 图标的 path 必须包 `<path d="…"/>`；改完务必"抽离静态骨架单独渲染截图"目视确认——DOM 里有 `<svg>` 不等于屏幕上画得出来。** 另：本环境对同一文件的并行 Edit 会互相覆盖（返回成功但磁盘未变），批量改色/改结构一律用 Python 脚本串行写盘，改完跑 `node --check web/app.js`。
