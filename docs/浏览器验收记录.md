- 关闭的详情抽屉不再绘制阴影或接收交互；显式设置根背景及中性滚动条，清除右侧残影。当前验收浏览器中未再出现右侧异常色边和横向溢出。用户截图中的 Safari 蓝条没有在原 Safari 中单独复测。
- 详细分析按机构结构、科室与专科、区域对比、网络与数据分组。13 张图表在可见时初始化。浏览器实际发现的旧网格跨列和旧百分比高度覆盖问题已修复。
- 办别分布改为数量排序条形图；等级与类型构成改为按家数堆叠条形图；专科分档去掉双轴累计折线；国家/市级专科按挂牌项数显示；协作网络改为横向堆叠；坐标仪表盘改为精确数量和比例。区域保留放大的等级矩阵，资源排名一次只比较一个指标。机构排名点击按机构 ID 打开详情。

- 问答先同步展示真实查询结果及完整结果入口，再请求智能说明。限流和连接失败保留本地结果，避免等待模型才能查看机构。中文输入法确认键不误发；忙碌时 Enter 不清空草稿、不能清空正在更新的对话。
- 联系方式页优先展示地址、电话、导航和官方平台入口，来源及多种导航方式按需展开。对比表去掉“越高越好”，本地化坐标精度和来源名称。
- 手机底部提供智能问答入口，浮动按钮不再覆盖移动端和分析图；390×844 视口中输入框、发送按钮均在底部导航上方。修复中等宽度深色主题的侧栏宽度。
- 数据整合页改为四步概览，技术处理细节折叠；删除固定过期的坐标覆盖率和本轮未测量的数据库扫描行数结论。

## 上线边界

本轮完成本地前端与关键交互验收，没有执行公网发布。模型接口实测存在限流；需要稳定的服务额度才能承诺智能说明的持续可用性。当前已经保证查询结果不依赖模型成功。

本次使用应用内真实浏览器及三种视口，未替代实体手机、独立 Safari/Chrome 跨浏览器测试、辅助技术测试、生产服务器负载与部署验收。未重跑 HDFS / Spark，也未修改数据库或新采集机构数据。
