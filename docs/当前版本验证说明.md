# 当前版本验证说明

本次改进以单文件大屏作为用户入口。数据快照日期保持原批次，构建日期和测试日期另行记录，不能把重新打包当成数据更新。

## 指标与证据

`etl/export_project_metrics.py` 从当前应用快照生成 `docs/当前项目指标.md`、`web/project_metrics.json`、`data/processed/project_metrics.csv`，并把同一份指标内联到页面的数据质量模块，支持下载 JSON。

指标记录值、分母、计算定义、来源文件和数据指纹。机构科室唯一组合、科室来源三元组和 CSV 原始行数分别统计，避免同名指标混用。

带库构建逐条导出科室来源；不带库构建仅在本地科室台账与快照每家机构的全部科室集合、有来源科室集合均一致时附加来源标签。无法验证则显示具体来源未载入。来源记录不等于当前在营确认，检查项目映射到科室不证明具备检查设备或服务。

## 筛选解释

机构查询页与解释面板共用 `web/app.query.js` 判断。科室、来源证据与半径调用 `NLQ.matches`。取消某条件后的数量，是保留其余条件后的真实计数；它不是多个单条件计数的相减或相加。

“仅有来源记录”与科室同时使用时，证据必须属于所选科室。无效半径不能静默退化为全量查询；旧快照缺证据字段时明确报错。默认排序与智能筛选统一为等级、科室收录量、名称，仅改变结果顺序，不是机构质量评分。

## 导航

左侧分组为查询与筛选、资源分析、数据治理、系统信息。机构查询与智能问答分别进入完整条件列表和聊天面板。原视图 ID 与深链接保持兼容，窄屏使用带提示的图标条，支持键盘焦点与选中状态。

## 重建与验证

在已安装项目依赖的 Python 环境运行。原项目的 Python 环境可通过 `PYTHON_BIN` 指定，不再要求某个个人绝对路径。

```bash
# 数据未更新，只改页面与代码时
PYTHON_BIN=python3 bash web/build_spa.sh --no-db

# 数据库已更新时，必须重新带库构建
PYTHON_BIN=python3 bash web/build_spa.sh

# 归档功能测试、一致性检查、数据指纹、源码哈希与引擎性能
python3 etl/validate_release.py

# 对已启动的 Flask/MySQL 服务额外测量只读接口；不调用大模型
python3 etl/validate_release.py --base-url http://127.0.0.1:5001 --samples 30 --concurrency 4
```

每次结果独立保存至 `data/validation/<UTC时间>/manifest.json` 和日志。性能记录均值、P95、样本数、并发数、环境和数据指纹。未提供服务地址则 HTTP 性能显示 skipped，不能作为接口通过证据。

Node 引擎基准包含解析、筛选和解释，排除浏览器绘制、网络传输、数据库、Spark。它不能替代固定最终部署环境的端到端性能。历史论文与答辩材料中的测试结论不能自动算成本批次实测。
